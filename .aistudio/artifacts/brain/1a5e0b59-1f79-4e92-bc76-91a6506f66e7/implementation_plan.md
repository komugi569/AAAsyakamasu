# 短答式（記述入力）モード ＆ スマート表記ゆれ・別名判定エンジン導入計画

既存の4択クイズバトルに加え、プレイヤーが自由に切り替えられる「短答式（記述入力）モード」を実装します。さらに、社会科特有の表記ゆれ（ヶ/ケ/が/ヵ/箇、漢数字と算用数字、有無が分かれる接尾語など）や歴史・地理・公民の別名・同義語（「二十一か条の要求」⇔「対華21ヶ条要求」、「間接民主制」⇔「代議制」⇔「議会制民主主義」、「聖徳太子」⇔「厩戸皇子/厩戸王」など）を漏れなく正解として判定するスマート正誤判定システムを構築します。

---

## User Review & Critical Decisions

> [!IMPORTANT]
> 事前のヒアリングでご回答いただいた以下の3つの基本方針に基づいて設計しています。内容をご確認の上、問題なければ「Proceed」で実装へ進みます。

- **Confirmed Decision 1（出題形式の切替）**: **4択モードと短答式（記述）モードを自由に切り替え可能にする**
  - タイトル画面およびバトル中の上部バー・コマンド待機画面から、ワンタップで「4択モード」「短答式（記述）モード」をいつでも切り替えられるようにします（設定は自動保存されます）。
- **Confirmed Decision 2（正誤判定の許容範囲）**: **表記ゆれ・別名・数字変換・定番の言い換えを幅広くすべて正解にする**
  - 多段階のテキスト正規化パイプライン（全角半角・漢数字⇔算用数字・ヶ/ケ/ヵ/箇/が・助詞や「式」の揺れ吸収）と、中学社会（地理・日本史・公民）の包括的な同義語・別名辞書を組み合わせ、別表現でもバツにならない判定を実現します。
- **Confirmed Decision 3（制限時間とヒント機能）**: **短答式では制限時間を長め（30秒）にし、文字数ヒントも表示する**
  - 短答式モード選択時は制限時間を **30.0秒**（即答クリティカル判定も12秒以内に緩和）に設定し、標準で「目安文字数バッジ（例：`目安: 5文字`、別名がある場合は別名の文字数も併記）」を表示します。さらに任意で「頭文字ヒントを見る」ボタンも用意し、タイピング詰まりを防ぎます。

## 1. Overview & Core Concept

- **What It Does**:
  1. **クイズ形式切替（4択 ⇔ 短答式）**: プレイヤーの学習段階に応じて、テンポよく進める「4択モード」と、記述力を鍛える「短答式（記述）モード」をシームレスに切り替えられます。
  2. **多段階スマート正誤判定エンジン**:
     - **文字・記号・数字の自動正規化**: 「二十一ヵ条の要求」「対華21箇条の要求」「21か条要求」のような漢数字・算用数字の混在や、「ヶ・ケ・ヵ・箇・か・が」の表記ゆれ、括弧書き補足、空白や句読点の違いを自動吸収します。
     - **接尾辞・表現パターンの柔軟許容**: 「リアス海岸 ⇔ リアス式海岸」「関ヶ原の戦い ⇔ 関ケ原の合戦 ⇔ 関が原の戦い」「〜条約 ⇔ 〜の条約」「〜制 ⇔ 〜制度」など、社会科で頻出する語尾・助詞のバリエーションを双方向で許容します。
     - **社会科特化の同義語・別名グループ辞書**:
       - **日本史**: 「聖徳太子 ⇔ 厩戸皇子 ⇔ 厩戸王」「中大兄皇子 ⇔ 天智天皇」「大海人皇子 ⇔ 天武天皇」「藤原道長 ⇔ 御堂関白」「二十一か条の要求 ⇔ 対華二十一か条要求」「鎖国 ⇔ 海禁政策」「太平洋戦争 ⇔ 大東亜戦争」「玄昉・吉備真備」などの人物別名・事件別称。
       - **公民**: 「間接民主制 ⇔ 代議制 ⇔ 議会制民主主義」「直接民主制 ⇔ 直接民主主義」「基本的人権 ⇔ 人権」「国際連合 ⇔ 国連」「日本銀行 ⇔ 日銀」「独占禁止法 ⇔ 独禁法」「少子高齢化 ⇔ 少子高齢社会」などの概念・略称・制度別名。
       - **地理**: 「リアス海岸 ⇔ リアス式海岸」「促成栽培 ⇔ 早作り」「抑制栽培 ⇔ 遅作り」「近郊農業 ⇔ 都市近郊農業」「四大工業地帯 ⇔ 太平洋ベルト」「東南アジア諸国連合 ⇔ ASEAN」などの用語・略称・英語表記。
     - **問題文・解説からの別名自動抽出**: 収録されている全1,449問の正解データ・解説文からも「別名〜」「〜とも呼ばれる」「（〜）」などの別表記を自動認識し、辞書と合わせて判定します。
  3. **ストレスのない短答式UI**:
     - 自動フォーカス付きのテキスト入力欄、Enterキーでの素早い回答送信（IME変換確定のEnterと回答送信のEnterを区別し、誤送信を防止）、文字数ヒント表示、ワンタップ頭文字ヒント、および回答後の「認識された別名・標準解答」の丁寧なフィードバックを備えます。

- **Target Audience / Persona**:
  - 中学社会（地理・日本史・公民）の定期テストや高校入試に向けて、選択問題だけでなく「用語を正確に書く・思い出す」実戦力を身につけたい学習者。

- **Key Value**:
  - 記述式クイズで最もストレスになる「意味や別名は合っているのに、表記の違いで不正解にされる理不尽さ」を解消し、RPGバトルの爽快感を保ったまま本格的な一問一答記述特訓が可能になります。

## 2. User Experience & Visual Design

- **Key User Flows**:
  1. **モード選択**: タイトル画面またはバトル画面上部のモード切替トグルから「4択モード（標準）」または「短答式（記述）モード」を選択します。
  2. **問題出題（短答式モード時）**:
     - 攻撃する分野（地理・日本史・公民）を選ぶと問題が表示され、タイマーが **30.0秒** からカウントダウンを開始します。
     - 問題文の下に「標準解答の文字数ヒント（例：`文字数目安: 7文字（別名回答もOK）`）」と、必要時に押せる「頭文字ヒントを表示」ボタン、および自動フォーカスされた回答入力フィールドが表示されます。
  3. **回答入力と判定**:
     - キーボードで答えを入力し（日本語入力の変換確定Enterでは誤送信されず、確定後のEnterまたは「回答して攻撃！」ボタンで送信）、即座にスマート判定エンジンが正誤を判定します。
     - 別名や表記ゆれで正解した場合も「正解！（標準表記：〇〇）」と分かりやすく表示され、会心の一撃や属性弱点・結界粉砕のダメージ計算がそのまま適用されます。
     - 分からない場合は「降参して答えを見る（パス）」ボタンで時間切れを待たずに解説へ進むことも可能です。

- **Visual Identity & Theme**:
  - **Aesthetic Direction**: 既存の羊皮紙（パーチメント）背景とダークスレートの魔導書バトルUI（`Zen Kaku Gothic New` × `Cinzel`）の世界観を完全に継承し、視認性の高い高コントラストな入力フォームを融合させます。
  - **Color Palette & Mood**:
    - ベースパネル: 深みのあるスレート（`bg-slate-900/95`）にインディゴ／アンバーの境界線。
    - 記述入力フォーム: 集中しやすいダークキャンバス（`bg-slate-950`）に、フォーカス時はアンバーの輝き（`focus-visible:ring-2 focus-visible:ring-amber-400`）。
    - 判定フィードバック: 正解時はエメラルド（`text-emerald-300` / `border-emerald-400`）、別名正解時は認識された別名と標準解答を並べて明示、不正解時はローズ（`text-rose-300`）で正解と解説を強調表示。
  - **Typography & Hierarchy**:
    - 入力文字は読み間違いが起きないよう大きめの太字（`text-base sm:text-lg font-bold tracking-wide`）を採用し、タイマーや文字数カウントには `font-mono tabular-nums` を適用します。

- **Interactive Feedback & Motion**:
  - 日本語IME入力中（`isComposing`）のEnterキー押下を厳密に検知し、漢字変換確定と同時に意図せず未完成の回答が送信されてしまう現象を防止します。
  - 頭文字ヒントボタンを押すと、正解（および主な別名）の最初の1文字がスムーズに開示されます。

## 3. Key Product Decisions & Trade-Offs

- **Decision 1: 多段階の正規化＋同義語グループ辞書による高速・確実なローカル判定**
  - *Chosen Approach*: 文字正規化パイプライン（数字変換・ヶ/ケ/が変換・接尾語正規化）と、社会科の同義語・別名グループ辞書、さらに問題解説文からの別名抽出を組み合わせたクライアントサイド判定エンジンを採用します。
  - *Why*: 通信待ち時間ゼロ（0ミリ秒）でRPGのテンポや即答クリティカル判定を損なわず、オフライン環境でも100%安定した判定が可能になるためです。
  - *Alternatives Considered*: 毎回外部APIに問い合わせる方式は、数秒の通信遅延が発生しバトルの爽快感やタイマー制と相性が悪いため採用しません。

- **Decision 2: 短答式モードにおけるタイマーとクリティカル基準の最適化**
  - *Chosen Approach*: 4択モードでは制限時間15秒（即答クリティカル5秒以内）を維持し、短答式モードでは制限時間30秒（即答クリティカル12秒以内）に自動調整します。
  - *Why*: スマートフォンやPCでの日本語タイピング・漢字変換にかかる時間を考慮し、焦りすぎずに「素早く思い出して入力すれば会心の一撃が出る」絶妙なゲームバランスを保つためです。

- **Decision 3: 問題事典・管理者ツールでの別名確認とカスタマイズ対応**
  - *Chosen Approach*: 各問題が持つ標準の正解に加え、システムが許容する別名・同義語リストを自動紐付けし、さらにカスタム問題追加時にも別名（カンマ区切り）を任意設定できるようにします。
  - *Why*: プレイヤーや管理者が「どんな別名が許容されるか」を確認・拡張でき、学習事典としての価値も高まるためです。

## 4. Technical Architecture & Data Strategy *(Technical Reference)*

- **Architecture & Component Diagram**:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        App State & Persistence                          │
│  - quizFormatMode: 'multiple_choice' | 'short_answer' (Saved in Storage)│
│  - Active Timer: 15.0s (4択) / 30.0s (短答式), Crit: 5.0s / 12.0s        │
└───────────────┬─────────────────────────────────────────┬───────────────┘
                │                                         │
                ▼                                         ▼
┌───────────────────────────────────┐     ┌───────────────────────────────┐
│   TitleScreen & HeaderNav         │     │           QuizArea            │
│  - 4択 ⇔ 短答式 モード切替トグル   │     │  - 4択ボタン群 (4択モード時)   │
│  - 現在の出題モードバッジ表示      │     │  - 短答入力フォーム (短答時)  │
└───────────────────────────────────┘     │    ・IME対応テキスト入力欄     │
                                          │    ・文字数目安 & 頭文字ヒント │
                                          │    ・パス(答えを見る)ボタン    │
                                          └───────────────┬───────────────┘
                                                          │ User Input
                                                          ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                  Smart Answer Matcher & Normalizer                      │
│  1. Text Normalization Pipeline:                                        │
│     - 全角/半角統一・空白/記号除去・括弧内補足処理                       │
│     - 漢数字 ⇔ 算用数字 統一変換 (二十一 ⇔ 21, 三大 ⇔ 3大, etc.)         │
│     - ヶ/ケ/ヵ/箇/か/が 統一変換 (関ヶ原/関ケ原/関が原, ヵ条/箇条/か条) │
│     - 接尾辞/助詞ゆれ正規化 (リアス[式]海岸, 〜[の]戦い/合戦/変/乱)      │
│  2. Synonym & Alias Equivalence Engine:                                 │
│     - 地理・日本史・公民 頻出別名・同義語・略称グループ辞書              │
│     - 問題データ・解説文からの別名・括弧表記の自動抽出マッチング         │
└─────────────────────────────────────────────────────────────────────────┘
```

- **Data Model & State**:
  - `QuizFormatMode`: `'multiple_choice' | 'short_answer'` をプレイヤー設定として追加し、`localStorage` に永続化します。
  - `QuizQuestion` / `ShuffledQuizQuestion`: 任意の `acceptedAnswers?: string[]` フィールドをサポートし、標準正解 `correctAnswer` と同義語辞書・正規化エンジンを組み合わせて判定します。
  - `AnswerEvaluationResult`: `{ isCorrect: boolean; matchedCanonical: string; isExactMatch: boolean; acceptedAliases: string[] }` を返し、別名で正解した際にも「あなたの回答：代議制（〇 正解！／標準表記：間接民主制）」のように学習効果の高い表示を行います。

- **Interactive Component & State Mapping**:
  - **モード切替ハンドラ**: タイトル画面のモード選択スイッチおよびヘッダーの切替ボタンから `quizFormatMode` を即座に更新し、進行中でない場合は次回出題およびタイマー上限（15秒 / 30秒）に即反映します。
  - **短答式入力・送信ハンドラ**:
    - 入力欄は問題表示時に自動フォーカス（`autoFocus`）され、`onCompositionStart` / `onCompositionEnd`（または `e.nativeEvent.isComposing`）を追跡してIME変換中のEnter誤送信をブロックします。
    - 「頭文字ヒント」ボタン押下時は、現在の問題の正解（および代表的な別名）の先頭文字を開示します。
    - 「パス（答えを見る）」ボタン押下時は、未入力のまま即座に判定フェーズへ移行し、正解と許容別名一覧・解説を表示します。
  - **復習リスト・結果画面連携**: バトル終了後の振り返り一覧（`ResultModal`）でも、自分が入力した文字列と正解（および別名）が並んで確認できるようにします。
